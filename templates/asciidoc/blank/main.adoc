== Getting Started

AsciiDoc is a lightweight markup language for authoring documents.
It supports many features out of the box:

* Ordered and unordered lists
* Tables and figures
* Code blocks with syntax highlighting
* Cross-references and footnotes

=== Code Example

[source,python]
----
def greet(name):
    return f"Hello, {name}!"

print(greet("World"))
----
